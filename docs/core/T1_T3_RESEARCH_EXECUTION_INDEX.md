## SET interpretation

Technology can stand alone as `T`, but often appears as:

- `S+T` when research needs data, models, scoring, dashboards, or reproducible analysis
- `E+T` when venture or operations work needs tools, automation, or interfaces
- `S+E+T` when research, decision logic, and implementation share one infrastructure layer
