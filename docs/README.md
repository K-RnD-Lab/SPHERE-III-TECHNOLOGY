# Active Docs - SPHERE III Technology

This folder is for active technology research and implementation work inside K R&D Lab.

Use `docs/` for:

- technical execution notes
- reusable tool and method guides
- dashboard and interface research packs
- reproducibility and scoring workflows
- GPT-assisted technical research workflows

Historical or superseded material should move to:

- `archived_docs/`

## Folder structure

- `docs/core/`
  - cross-track technology execution notes
  - T1-T3 research execution index
  - structure approval gate
  - GPT-assisted technology workflow

## Current active logic

SPHERE III should not become a random tool list.

It should answer:

- what technical system is needed
- what method, pipeline, dashboard, or interface makes the work reusable
- what can be tested, regenerated, deployed, or inspected
- how the tool supports `S`, `E`, `S+T`, `E+T`, or `S+E+T`

## Before execution

Use `docs/core/TECHNOLOGY_STRUCTURE_APPROVAL_GATE.md` before turning a technical topic into a build or research artifact.

Use `docs/core/T1_T3_RESEARCH_EXECUTION_INDEX.md` as the cross-track index for deciding which technology route to execute next.

Use `docs/core/GPT_ASSISTED_TECHNOLOGY_WORKFLOW.md` when a technology research pack is being sent into GPT and returned as repo-ready `.md` output.
