# 🤖 T1 — AI / Data Analytics

## Focus
ML pipelines, biomedical AI, data analytics, and scoring systems.

## Tools & Packages
- [bioscore](https://pypi.org/project/bioscore/) — reproducibility audit, data quality, model readiness
- [set-method](https://pypi.org/project/set-method/) — SET classification, scoring, quest recommendation
- [studyreg](https://pypi.org/project/studyreg/) — study pre-registration and search

## HF Spaces
- [bioscore demo](https://huggingface.co/spaces/K-RnD-Lab/bioscore) — upload notebooks, CSV, models
- [set-method demo](https://huggingface.co/spaces/K-RnD-Lab/set-method) — classify and score projects
- [studyreg demo](https://huggingface.co/spaces/K-RnD-Lab/studyreg) — register studies

## Starter Tasks
1. Install: `pip install bioscore set-method studyreg`
2. Score a notebook: `bioscore.reproducibility('notebook.ipynb')`
3. Classify a project: `set_method.classify('oncology ML pipeline')`
4. Register a study: `studyreg.register('My Study', 'https://github.com/...')`
