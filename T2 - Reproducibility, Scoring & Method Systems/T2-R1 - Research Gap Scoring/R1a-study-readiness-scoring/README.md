# R1a Study Readiness Scoring

## Question

How can K R&D Lab score whether a study is ready to move from exploratory computational work into a more reproducible or experimentally actionable stage?

## Scope

This starter study focuses on evaluation logic, confidence labels, and reproducibility criteria.

## Method

1. Define scoring dimensions for evidence density, reproducibility, novelty, and experimental handoff readiness.
2. Separate exploratory scores from near-validation scores.
3. Document confidence labels and decision thresholds.
4. Test whether the scoring system is understandable across science and technology studies.

## Candidate scoring dimensions

- evidence coverage
- data quality and traceability
- methodological reproducibility
- translational or experimental handoff clarity

## Status

Starter scaffold for a reusable scoring framework.
